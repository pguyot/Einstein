# Einstein Prefs

Einstein Prefs is the NewtonOS app that sets up the emulator from inside the
Newton, for example the driver of the serial port (Extras › Einstein, or the
*Einstein* icon at the end of the button bar).

`EinsteinPrefs.pkg` is built into the Einstein REx (see `../Einstein.rex.src`).
For now, only the compiled package is here. The source code (a Newton Toolkit
project) will be added later.
